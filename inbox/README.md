# Inbox manual

Pega aquí, como archivos `.txt` o `.md`, publicaciones de grupos privados a los que perteneces (Facebook, LinkedIn,
Slack o WhatsApp de comunidades) que el agente no puede leer por sí mismo. Incluye el enlace si lo tienes.

Cada ejecución los analiza junto con las fuentes web y luego los mueve a `inbox/processed/`.
Puedes subirlos desde el navegador o el móvil con "Add file" en GitHub.
